# Assets

Colocar os arquivos web em `apps/web/public/assets/`, nas pastas backgrounds, characters, objects, models, audio e videos. Referenciar pela URL `/assets/...`.

O aplicativo mobile deve empacotar os arquivos necessários em seu próprio diretório de assets. Compartilhar identificadores e conteúdo; adaptar o carregamento por plataforma.

Registrar aqui cada arquivo final: autor, origem, licença/condições de uso, ferramenta utilizada e crédito exigido. Nenhum asset externo foi incorporado na base inicial.
